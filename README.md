# Techtalk — Responsive Tech Product Landing Page

A responsive landing page for **Techtalk**, a fictional technology retail brand, designed as a frontend development task focusing on responsive layouts, product presentation, user experience, and interactive theme switching.

## Overview

This project implements a modern landing page for Techtalk, showcasing different technology products such as smartwatches, earbuds, smartphones, laptops, tablets, and custom-built PCs.
The interface includes a navigation bar, hero section, product catalog, feature highlights, customer reviews, pricing plans, and showroom information.
It is built using **HTML5, CSS3, Bootstrap 5, and vanilla JavaScript**, with a focus on responsive design, organized content sections, and interactive user experiences.

## Features

- Responsive landing page for desktop, tablet, and mobile devices
- Navigation bar with links to different page sections
- Hero section with promotional content and call-to-action buttons
- Product catalog with technology product categories
- Product search and category filtering
- Product cards with descriptions and prices
- Light and dark theme toggle
- Theme preference saved using localStorage
- Feature section highlighting the benefits of Techtalk
- Customer testimonial and review section
- Pricing section featuring Techtalk Care Plans
- Showroom information and store details
- Bootstrap Icons for visual elements
- Responsive layouts using Bootstrap Grid and CSS
- Smooth visual styling and interactive elements

## Technologies Used

- **HTML5** — Semantic page structure and content organization
- **CSS3** — Custom styling, responsive layouts, transitions, and theme variables
- **Bootstrap 5** — Responsive grid system, navigation, buttons, and layout utilities
- **JavaScript ES6+** — DOM manipulation, event handling, product interactions, and theme switching
- **Bootstrap Icons** — Icons for navigation, products, and interface elements
- **Local Storage API** — Saving the user's selected theme preference

## Technical Implementation

### Responsive Layout

The project uses the Bootstrap grid system and responsive utility classes to organize content across different screen sizes.
CSS media queries and flexible layouts help maintain a consistent appearance on desktop, tablet, and mobile devices.

### Landing Page Structure

The page is divided into multiple sections to create a clear content hierarchy:

- Navigation bar for accessing different sections
- Hero section for introducing the Techtalk brand
- Product catalog for displaying available devices
- Features section for highlighting store benefits
- Reviews section for presenting customer feedback
- Pricing section for showcasing device care plans
- Showroom section for displaying store information

### Product Search and Filtering

JavaScript handles product-related interactions, allowing users to explore the product catalog through search and category-based filtering.

### Theme Toggle

The project includes a light and dark mode feature using JavaScript.
The theme toggle updates the page appearance by changing the Bootstrap theme attribute. The selected preference is stored in localStorage so it can be restored when the user revisits the page.

### Bootstrap Integration

Bootstrap 5 provides the responsive grid system, navigation components, buttons, and utility classes. Bootstrap Icons are used to improve visual communication throughout the interface.

### User Experience

The interface uses clear headings, product cards, descriptive content, and call-to-action buttons to make the landing page easier to navigate and understand.
